# Deep Belief Networks on Fashion-MNIST

Computer Vision project focused on image classification using Deep Belief Networks (DBN) and Restricted Boltzmann Machines (RBM) implemented in PyTorch.
The project investigates unsupervised pretraining techniques and deep probabilistic architectures on the Fashion-MNIST dataset.


## Project Overview
The notebook includes:

- data preprocessing and visualization
- Restricted Boltzmann Machine implementation
- Deep Belief Network architecture
- unsupervised layer-wise pretraining
- supervised fine-tuning
- model evaluation on Fashion-MNIST

The project explores the role of generative pretraining for image classification tasks.

## Dataset
The project uses the Fashion-MNIST dataset, containing 70,000 grayscale images of clothing items divided into 10 categories.
Each image has resolution:
- 28 × 28 pixels
Dataset reference:
- Xiao et al. (2017)
